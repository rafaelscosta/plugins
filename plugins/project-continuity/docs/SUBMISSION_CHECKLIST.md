# Public Submission Checklist

## Package

- [x] `.codex-plugin/plugin.json` exists.
- [x] `skills/project-continuity/SKILL.md` exists.
- [x] Plugin and skill identity length is within limits.
- [x] Skills-only archive contains no `.app.json`, `.mcp.json`, `apps`, `mcpServers`, hooks, or screenshots.
- [x] Logo and composer icon are square, readable PNG files.
- [x] Starter prompts are unique, single-line, and within directory limits.
- [x] Local automated validation passes.
- [x] Original PCP/1 test suite passes inside the plugin.

## Account and portal work

- [ ] Select the OpenAI Platform organization that will own the plugin.
- [ ] Confirm Apps Management write permission for the submitter.
- [ ] Complete individual or business identity verification.
- [ ] Confirm the verified identity matches the chosen public developer name.
- [ ] Open the plugin submission portal and choose **Skills only**.
- [ ] Upload `project-continuity-plugin-v1.0.0.zip`.
- [ ] Review any manifest normalization proposed by the portal.
- [ ] Complete country availability and policy attestations.
- [ ] Run and pass the portal safety/security scans.
- [ ] Submit for review.

## Optional listing links

Skills-only package validation permits omitting website, support, privacy, and terms URLs. Add only real public HTTPS URLs owned by the verified publisher; never add placeholders.
